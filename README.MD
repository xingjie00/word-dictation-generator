# 单词听写生成器 (Word Dictation Generator)

一个基于 Python 和 PyQt6 的图形化工具，用于生成可定制的英语单词听写练习文档。教师或家长可以轻松创建包含重点复习和随机抽查的每日听写练习。

## ✨ 功能特性

- **可视化界面**：直观的GUI操作，无需命令行知识
- **灵活配置**：自定义每日单词总量、重点单词数、练习天数
- **智能单元选择**：支持选择重点单元和多个复习单元
- **均衡抽取**：每天的名额按随机权重分配到各单元（保底 1 个/单元），再单元内随机选词，避免单词扎堆在个别章节
- **独立去重**：重点与复习各自保证当天内部不重复、互不比较；跨天允许再现，天然形成间隔复习
- **专业文档输出**：自动生成格式规范的HTML文档，包含表格、标题和统计信息
- **参考答案页**：文档末尾自动追加"参考答案"页，按天分组、两栏紧凑排版，批改无需回查词库
- **独立预览**：生成前可点击"预览"按钮在浏览器中查看效果，无需保存
- **词库管理**：在界面中直接新增、修改、删除单词，支持重命名/删除整个单元与导出词库，即时生效
- **批量导入**：词库管理支持粘贴或从 .txt 文件批量导入词表（每行"英文 释义"）
- **SQLite 词库**：单词数据存储在轻量级数据库中，首次运行自动从种子导入
- **进度反馈**：生成文档时显示进度条
- **配置持久化**：自动保存用户设置，下次启动无需重复配置

## 🚀 快速开始

### 环境要求
- Python 3.8+
- 推荐使用虚拟环境

### 安装与运行
```bash
pip install -r requirements.txt
python main.py
```

首次启动时，程序会自动把 `resources/words.json` 导入 SQLite 词库 `resources/words.db`，之后所有词库读写都走数据库。

## 📖 使用方法

### 基本流程
1. 启动程序后，在"选择单元"标签页：

- 选择一个重点单元（可选）

- 选择多个复习单元

2. 在"设置参数"标签页调整：

- 每日单词总数（默认：18个）

- 重点单词数（默认：10个）

- 练习天数（默认：5天）

- 输出文件名

3. 点击"预览"按钮可在浏览器中预览效果（不保存）

4. 点击"生成HTML听写文档"按钮，选择保存位置，等待生成完成

生成的文档除每日题目页外，末尾会自动附带一页"参考答案"（见下文）。

### 参考答案页

生成的 HTML 文档最后自动追加一页"参考答案"，打印时独立成最后一页：

- **按天分组**：以"第1天…第N天"小标题分组，组内顺序与题目页（重点 → 复习）一致
- **条目格式**：`序号. 英文 — 释义`，每天内从 1 连续编号
- **紧凑两栏排版**：小字号多栏布局，约 90 个单词的答案占 1 页 A4 左右（依浏览器/打印机略有差异）
- **去重规则**：同一单词同一天只列一次（当天既是重点又是复习时不重复）；跨天重复正常保留，与间隔复习语义一致
- **释义实时取值**：显示词库当前值，包含通过"词库管理 → 修改所选"改过的内容
- 空文档（无任何单词）时不会生成空的答案页

### 词库管理
在"词库管理"标签页中：

- 选择"添加到新单元"并输入单元名称，或选择"添加到已有单元"

- 输入英文单词和中文释义，点击"添加到暂存"

- 批量导入：在"批量导入"框中粘贴词表（每行"英文 释义"，空格/Tab/逗号分隔），或点击"从文件导入…"选择 .txt 文件，再点"解析加入暂存"

- 可添加多个单词到暂存列表；暂存中可移除未保存的项

- 点击"保存到词库"写入 SQLite 词库，保存后即时生效

- 修改/删除：在已入库单词列表中选中条目，"修改所选"可编辑英文与释义，"删除所选"支持多选批量删除，改动即时生效并反映到后续生成的文档（含答案页）

- 单元操作："修改单元名"重命名当前单元（顺序、单词与抽查次数不变）；"删除整个单元"连同其全部单词一并删除（均需确认）

- 导出词库：点击"导出词库…"可把全部词库导出为 JSON 文件（格式与初始种子 words.json 一致，可再次导入）

## 🗄️ 词库存储说明（SQLite）

自 v3.0 起，单词数据存储在 `resources/words.db`（SQLite 数据库）：

- **首次运行**：自动从 `words.json` 种子导入，之后以数据库为准
- **日常增词**：用程序内"词库管理"标签页（推荐），直接写库即时生效；支持单个添加与批量导入
- **重置词库**：删除 `resources/words.db` 后重启程序，将重新从 `words.json` 导入初始词库
- **打包分发**：`build.py` 会把当前 `resources/words.db`（含词库管理中添加的词）随包放进 `dist/resources`，收到即用；`words.json` 不出现在发布包中，仅内置 exe 作为重置种子
- `words.json` 仅作为初始种子保留。直接编辑它不会影响已生成的 `words.db`；若编辑了种子并想重建词库，先删除 `words.db` 再启动程序

### 种子文件格式（words.json）
``` json
{
  "word_list": [
    {
      "unit": "Unit 1",
      "words": [
        {"word": "apple", "translation": "苹果"},
        {"word": "book", "translation": "书"}
      ]
    },
    {
      "unit": "Unit 2",
      "words": [
        {"word": "dog", "translation": "狗"}
      ]
    }
  ]
}
```

## 🔄 选词算法与去重规则
- **每天独立抽取**：每一天都重新按随机权重分配名额并随机选词，天与天之间互不影响
- **随机权重分配**：各单元的名额按 Dirichlet 随机权重分配（期望比例≈单元词量比例，带随机波动）；名额不少于单元数时每单元保底 1 个，且不超过其可用词量
- **当天不重复（各部分独立）**：重点与复习各自按英文单词字符串去重，两部分之间互不比较——共享词可以同一天既作重点又作复习；同一单词在多个单元中都有时当天在该部分内只出现一次，释义取当天抽到它的那个单元的版本
- **跨天允许重复**：单词可以在不同天再次出现——这正是复习所需的间隔重复；也因此只需"当天词量够当天抽取"，不再要求整个周期的去重总量
- **不足报错**：如果当天可用单词不足以填满当日抽取量，会提示具体的缺少数量和建议

## 📦 打包发布
```bash
python build.py
```
构建产物在 `dist/`：单文件 exe + `resources/`（config.json、words.db 当前词库）。词库开箱即用，无需等待首次导入；删除 words.db 后重启程序可从 exe 内置种子重置词库。构建横幅会显示当前版本号（来自 `src/version.py`）。

## 🔢 版本号

版本号单一来源：`src/version.py` 中的 `__version__`（语义化版本 MAJOR.MINOR.PATCH，当前 `3.0.0`）。

- GUI 窗口标题、界面横幅与 `build.py` 构建横幅均实时引用该常量，发布新版本只需修改这一处
- exe 文件属性中的版本信息暂未写入（需后续生成 PyInstaller version-file，属打包流程变更）
